# WRITING.md — Jitu (jituptn.com)

Reference for every word on the site and in the app: landing, student app, admin, emails, WhatsApp notices. Pairs with `design.md` (which strictly governs visual design, layout, tokens, and components). For all copy decisions, voice, and microcopy, this file is the sole authority. Document in English; all shipped copy in Indonesian.

## 1. Four values
1. **Information efficiency.** Every line changes what the reader knows or does. If it doesn't, delete it.
2. **Sounds like a person.** The register of siakjuara.com: casual, direct, a little cheeky. Never corporate.
3. **Proof over praise.** A number, date, formula or real screen beats an adjective.
4. **Doesn't read generated.** No template rhythm, no stock phrases, no tidy symmetry.

## 2. What we take from siakjuara.com (and what we leave)

**Patterns to borrow** (patterns, not phrases; never copy their lines):
- **Inverted headline.** Two short clauses that flip the expected order: "Menang Duluan, Bayar Belakangan". Ours: "Kerjakan gratis. Bayar kalau mau tahu salahnya di mana."
- **Colloquial support line** right under the headline, said the way you'd say it to a friend.
- **Section titles as the reader's question**, answered by the next line: "Gimana cara mainnya?" Ours: "Bayarnya gimana?"
- **Price inside the heading**, in short form: "Tarif Flat 200k". Ours: "Mulai Rp8.900 per tryout".
- **Formula block + worked example.** A labelled formula, then one concrete case with a result. This is their best device because it makes the price checkable in five seconds.
- **Scarcity as data**, never as adjectives: slot counts per faculty (48/50). We have no real quota, so our version is **time**: "Tryout #1 dibuka 2 Nov". Never fake scarcity.
- **Full name under the abbreviation** (FEB → Ekonomi dan Bisnis). Use for school names and subtest codes.
- **Plain legal line**, small, in normal language.

**Do not copy:**
- Emoji in headings and bullets (design.md bans emoji).
- A headline stat we can't source. We have no win-rate-style number; don't ship any stat without a source.
- Overclaims ("fix menang") and filler ("Simple banget, ga pake ribet"). That sentence says nothing; the formula does the work.
- Exclamation-mark urgency ("Terbatas banget!").
- Unfinished defaults. Their page ships with a meta description of "Generated by create next app". We write a real `<title>` and meta description (≤155 characters) on every page.

## 3. Voice

| Rule | Detail |
|---|---|
| Address | "kamu". Never "Anda", never "para pelajar". |
| Register | Casual but readable by a 16-year-old and her parent. "banget", "nggak", "gimana" are fine in marketing. App UI is neutral and short. **Test-taking screens have zero personality: labels only.** |
| Spelling | Pick one casual form and keep it: "nggak" (not "ga"/"gak"). Standard spelling elsewhere. |
| English words | Only established ones, e.g. "tryout". Otherwise Indonesian: "Masuk" not "Login", "Daftar" not "Sign up", "coins" not "kuota" / "koin". |
| Humor | One light line per page at most, never on prices, errors, or the test screen. |
| Stance | Say what the product does and doesn't do. Admitting a limit builds more trust than a superlative. |

## 4. Information efficiency

**Order inside any block:** what it is → what it costs → when → what to do next.

**Rules**
- Answer first. No warm-up sentence.
- One idea per sentence. Average ≤20 words; hard cap 28 in marketing, 14 in UI.
- Number before adjective. If an adjective can't be measured, cut it.
- Say each fact once per page. Later mentions point back ("harga di atas").
- Prefer a table, formula, or real UI sample over a paragraph that describes one.
- Prices always carry their unit: "Rp59.000 untuk 5 coins (Rp11.800 per tryout)".
- Formats: Rp15.000 (dot thousands), "2 Nov 2026", 24-hour time, "90 menit".
- Locked or paid actions state the cost on the control: "Buka · 1 coin".

**Word budgets**
| Element | Limit |
|---|---|
| H1 | ≤10 words |
| H2 | ≤8 words |
| Hero support line | ≤25 words |
| Section intro | ≤2 sentences |
| Button | 1–3 words, verb first |
| Modal title / body | ≤6 words / ≤2 sentences |
| Toast | ≤8 words |
| Error | ≤2 sentences: what happened + what to do |
| Empty state | 1 sentence + 1 button |
| Meta description | ≤155 characters |

**Delete test:** remove the line. If nobody would miss it, it stays removed.

## 5. Anti-AI structure

Generated copy is recognisable by shape before wording. Check both.

**Structural tells to avoid**
| Pattern | Do instead |
|---|---|
| "Bukan hanya X, tetapi juga Y" / "Not just X, it's Y" | State Y. Allowed once per page, only if readers truly believe X. |
| Lists that always have exactly three parallel items | List as many items as are true, in uneven lengths. |
| Bullets with a bold lead-in ("**Cepat:** …") | Plain sentence, or a table. |
| Row of three cards: icon + title + two-line blurb | Real UI sample, numbered steps, or a table. |
| Title Case headings, or "Topik: Subjudul" with a colon | Sentence-case statement or question. |
| A closing sentence that summarises the section | Stop when the information ends. |
| A sentence that restates its heading | Delete it. |
| Rhetorical-question opener ("Siap menaklukkan UTBK?") | Question headings only when the next line answers them. |
| Every sentence the same length and rhythm | Mix long and short. Fragments are fine if they carry information. |
| Em dashes as punctuation habit | Period or comma. None in UI copy. |
| Hedging ("sekitar", "umumnya", "mungkin") | State the number, or state the real range. |
| Flattery ("pelajar cerdas sepertimu") | Say nothing about the reader's character. |
| Emoji as bullets or decoration | None. |

**Banned vocabulary**
- Indonesian: terbaik, terdepan, revolusioner, inovatif, komprehensif, holistik, solusi (as a noun for our product), ekosistem, optimal/maksimal (as filler), berbagai macam, selamat datang di, di era digital, raih impianmu, wujudkan, perjalananmu, tingkatkan potensimu, mari/yuk kita, dengan demikian.
- English leakage: unlock, elevate, seamless, powerful, leverage, game-changer, next-level.

**Specificity rule:** every claim carries a number, date, name, or mechanism. "Pembahasan tiap soal" passes. "Pembahasan berkualitas" fails.

**Swap test:** put a competitor's name in place of ours. If the sentence still reads true, rewrite it.

## 6. Pattern library

**Headline formulas**
1. Inversion: "Kerjakan gratis. Bayar kalau mau tahu salahnya di mana."
2. Number first: "Tryout tiap minggu. 2 Nov 2026 sampai 21 Apr 2027."
3. Question → answer: "Bayarnya gimana?" / "Tryout gratis. Coins cuma buat pembahasan."

**Formula + example (pricing)**
```
HARGA PER TRYOUT
harga paket ÷ jumlah coins

Contoh: 10 coins
Rp89.000 ÷ 10 = Rp8.900 per tryout
```

**Microcopy**
| Context | Copy |
|---|---|
| Primary CTAs | Daftar gratis · Kerjakan · Kumpulkan · Buka · 1 coin |
| Empty | "Belum ada tryout yang dikerjakan. Tryout #1 dibuka 2 Nov." |
| Offline | "Tidak ada koneksi. Jawabanmu tersimpan di perangkat." |
| Submit modal | Title "Kumpulkan sekarang?" Body "11 dijawab, 1 ragu, 8 kosong." |
| Unlock modal | "Pakai 1 coin untuk Tryout #3? Sisa coins jadi 4. Ini tidak bisa dibatalkan." |
| Form error | "Kata sandi minimal 8 karakter." (say the rule, not "Input tidak valid") |
| Generic failure | "Gagal menyimpan. Coba lagi." Never "Oops!" |
| Timer, last 5 min | "Sisa 5 menit." No jokes. |
